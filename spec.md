GoalHub

About the Project
Football League Hub is a football mobile application for all football fans, who want to get easy access to the top three European football leagues (Premier League, La Liga and Serie A). The application displays some basic football information like today's football matches, upcoming football matches, football result, teams, football league, players, match details.
The app will have four main screens: Home, Leagues, Teams, and Match Details. Users can choose a league, display the teams within the league and the league table, and choose a team to display information and matches, and can open a match to display the teams playing, date, time, stadium, and result.
It will also have a simple “Predict the Match” feature to make the application more interesting. The user can guess which team A, B or neither is going to win. A simple gaming element is added to the app as users can earn points if they get their prediction right.
The first iteration will be based on local JSON or SQLite data instead of a realtime football API. This makes the project simple and suitable for a beginner level mobile application project.

Problem Statement
Football fans often have to use various websites or apps to find out information about football matches, teams, league standings, and results. A number of advanced features are also offered by most football applications that can make them too complicated for users looking for basic football information.
Everybody wants a sports mobile app that is simple and easy to use and has basic information about Premier League, La Liga and Serie A. Also, users may not be as interactive when they view football information.
Hence, this project is targeted to be a simple football mobile application which could be used to access the information related to the league, teams, matches, results, and standings in a single application and also a basic match prediction feature to make the thing more interactive and entertaining.

Objectives
The primary goal of this project is to create an easy-to-use football mobile application to keep track of the top three European football leagues.

Specific Objectives
To give details of the three biggest football leagues (Premier League, La Liga and Serie A).
To show information about football games such as today's games, next games and past games.
To give out league tables that include teams, points, wins, draws and losses.
To deliver data about the team such as team logos, team players, game data, and base statistics.
To include detailed information about the match including teams, date, time, stadium and score/result.
To add a simple match prediction feature to the app, in which users can predict the result of a match.
To add a simple points system to award users for making correct match predictions.
In the first version to keep things simple and easy to use, using local JSON or SQLite storage.
Provide an intuitive and user-friendly interface with four major screens: Home, Leagues, Teams and Match Details.
